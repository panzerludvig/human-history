## The process

**The conflict rule changed.** It allowed a night merge only when both sides were pure additions, and deferred 17 over a hunk where 11 inserted a line directly above one 17 rewrote: no decision in it at all. It is now the run's judgement of whether the two changes are independent, bounded by never writing a line neither order wrote, with each hunk explained in both Run sections (`work_orders/README.md` step 4, [[Meta/Work Orders]]). The merge of 12 needed one such line, a merged comment, and was made on the developer's instruction as a recorded deviation.

**World totals no longer gate an order.** 11 and 12 each missed a single-run guard on settlements, people or farming at year 700. Tonight's own runs show one run moves those by more than 10% from any change to an early random draw, and farming by several times. The checks now test the order's mechanism; totals are quoted for the morning, and whether the new world is good is the developer's call (planning checklist, item 3).

**Parallel orders cost the timing checks.** Implementing six orders at once loaded the machine to 100% for hours; every timing comparison was made back to back under that load and says so.

**The stall.** The second probe for 11 and 12 ended by loading 12's pre-order saves in the game with a screenshot argument but no `HH_BENCH`; a screenshot run without it keeps running for interaction, so the game sat open and the run waited on it from 23:25 until the developer asked in the morning. Probe scripts that start the game set `HH_BENCH`.
