# Status Vocabulary

Every design and technical note states its status at the top. The fixed set:

| Status | Meaning |
|--------|---------|
| Stub | Placeholder; the topic is named but nothing is decided |
| Concept | Direction exists; key questions open |
| Designed | Decided on paper; not yet implemented |
| Implemented | Exists in code and can be tried |
| Proven | Implemented and confirmed to do what the design wanted |

Move a note forward only when the criterion is actually met. Moving backward is allowed — write the reason in [[Dev Log/Log]].
