# Inherited from Delegate

What this vault took from the Delegate project (https://github.com/panzerludvig/delegate) and what it deliberately did not.

---

## Kept

- The Codex as the Claude briefing document, with short entries linking to dedicated notes ([[Meta/Codex Guidelines]])
- The Meta system: [[Meta/Suggestions]], [[Meta/Todo]], [[Meta/Quick Notes]], [[Meta/Open Threads]], [[Meta/Recurring Tasks]]
- The Dev Log as a reasoning archive, not a changelog ([[Dev Log/Log]])
- Session boundaries declared explicitly by the user
- Folder layout and note conventions ([[Meta/Obsidian]])
- Obsidian core-plugin configuration

## Changed

- [[Meta/Git]] conventions filled in (they were stubs in Delegate)
- A [[Meta/Status Vocabulary]] defined (Delegate had this as an open todo)
- [[Meta/Incremental Design]] added as a Codex principle — the main lesson from Delegate
- [[Meta/Open Threads]] given a format and promoted to a Codex entry

## Not kept

None of Delegate's design content was copied. Its concepts — event-driven simulation, map-centric design, autonomy, agents, administrators, objects, tech tree, diplomacy — are candidates to re-examine one at a time when the core needs them, not a starting point. They are listed as candidates in [[Design/Core Concepts]] so they aren't forgotten, but none are decided.
